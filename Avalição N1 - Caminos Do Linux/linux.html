Linux e distribuição: qual é a diferença?

Todo sistema precisa de uma parte que organize o uso da memória, do processador e dos dispositivos. Essa parte é o núcleo, também chamado de kernel. Linux é um kernel.

Uma distribuição reúne esse núcleo, ferramentas, aplicativos e um jeito de instalar e atualizar tudo. É esse conjunto que você baixa para usar no computador. Zorin OS, Linux Mint e Bazzite são distribuições Linux.

A explicação do projeto do kernel faz essa distinção: para começar a usar o sistema, procure uma distribuição, e não o kernel isolado.

O que muda para quem usa Windows

Windows e uma distribuição Linux cumprem o mesmo papel no computador: oferecem um ambiente para executar programas e cuidar dos arquivos. O Windows é desenvolvido pela Microsoft; as distribuições são mantidas por diferentes empresas e comunidades.

Na prática, algumas diferenças aparecem logo no começo:

  • Você pode escolher entre distribuições e interfaces com propostas diferentes.
  • Os aplicativos costumam vir de uma central de programas ou de repositórios mantidos pelos projetos.
  • Um instalador .exe do Windows não funciona diretamente como um aplicativo Linux. Pode ser necessário procurar uma versão própria ou uma alternativa.

A compatibilidade dos programas merece mais atenção que a aparência. Uma interface familiar ajuda, mas não garante que todas as ferramentas usadas no Windows estarão disponíveis.

Software livre e um pouco de história

Software livre permite executar, estudar, modificar e compartilhar um programa, respeitando sua licença. Para estudar e modificar, é preciso ter acesso ao código-fonte, o texto usado para construir o programa. Livre se refere a essas liberdades; o programa pode ser gratuito ou vendido.

O kernel Linux começou em 1991, com Linus Torvalds. Seu desenvolvimento passou a receber contribuições de outras pessoas. Ferramentas do projeto GNU, que já trabalhava em um sistema livre, ajudaram a formar sistemas completos com esse núcleo.

Por isso, você também encontra o nome GNU/Linux. Muitas distribuições combinam software livre com componentes proprietários, como alguns drivers; usar Linux não significa que todos os programas instalados sejam livres.

Para consultar as fontes, leia a definição de software livre do GNU e o contexto sobre GNU e Linux.

O ambiente gráfico e o terminal

O ambiente gráfico reúne os menus, as janelas, o painel e outras partes da interface. É o que permite abrir programas e organizar arquivos com o mouse. Cinnamon, GNOME e KDE Plasma são exemplos.

O terminal recebe instruções escritas. Ele pode ajudar a repetir tarefas ou investigar problemas, mas não é preciso passar o dia inteiro nele. Navegar na internet, editar documentos e instalar muitos aplicativos são tarefas que podem ser feitas pela interface gráfica.

Um primeiro contato pela interface

  1. Abra o menu de aplicativos e procure o navegador.
  2. Use o gerenciador de arquivos para encontrar sua pasta pessoal.
  3. Abra as configurações para conferir idioma, som e rede.

Esse teste já mostra boa parte do que você usará no cotidiano.

Termos que aparecem com frequência

Distribuição ou distro
Sistema completo montado a partir do kernel Linux e de outros componentes.
Repositório
Local de onde o sistema obtém programas e atualizações. Prefira as fontes recomendadas pela distribuição.
Driver
Componente que permite ao sistema trabalhar com um dispositivo, como uma placa de vídeo ou impressora.
Imagem ISO
Arquivo que reúne o conteúdo usado para preparar uma mídia de instalação. Geralmente tem a extensão .iso.
Live USB
Pendrive preparado para iniciar um sistema. Nas distribuições que oferecem uma sessão de teste, ele permite experimentar antes de instalar. A sigla USB vem de Universal Serial Bus, um padrão de conexão usado por esses dispositivos.
Partição
Divisão do espaço de um disco. Pode separar o Windows, o Linux e outras áreas de armazenamento.

Com esses nomes em mente, fica mais fácil comparar as distribuições.
