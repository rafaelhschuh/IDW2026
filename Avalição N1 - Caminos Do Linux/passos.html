Experimente antes de instalar

Um Live USB é um pendrive preparado para iniciar um sistema. Zorin OS e Linux Mint oferecem uma sessão de teste: você pode conhecer a interface sem instalar no disco interno. No Bazzite, consulte o guia da versão escolhida; não presuma que a mídia de instalação oferece o mesmo teste.

Outra opção é uma máquina virtual, que executa o sistema dentro do Windows. Ela ajuda a conhecer os menus, mas não representa bem o desempenho dos jogos ou a compatibilidade real dos dispositivos.

O caminho básico com um pendrive

  1. Baixe a imagem ISO no site oficial da distribuição e confira os requisitos e a integridade do arquivo conforme o guia.
  2. Copie os arquivos importantes do pendrive para outro lugar. A gravação da imagem apaga seu conteúdo.
  3. Use a ferramenta indicada no guia para gravar a ISO. Copiar o arquivo para o pendrive não basta.
  4. Reinicie o computador e escolha o pendrive no menu de inicialização. A tecla desse menu varia conforme o fabricante.
  5. Quando houver essa opção, escolha experimentar o sistema e teste rede, som, vídeo e teclado antes de abrir o instalador.

Durante o teste, não altere as partições nem os arquivos do disco interno. Em uma sessão comum, sem persistência configurada, as alterações feitas no ambiente de teste se perdem ao desligar.

Veja os procedimentos completos nos guias de instalação do Zorin OS, teste do Linux Mint e instalação do Bazzite.

Backup e cuidados com a instalação

Faça backup antes de mexer no disco. Guarde documentos, fotos e trabalhos em outro dispositivo ou serviço de armazenamento e abra alguns arquivos da cópia para conferir se estão acessíveis.

Tenha tempo para ler as telas do instalador. Se não entender uma opção de disco ou partição, consulte o guia antes de continuar.

  • Confira o espaço disponível e os requisitos da distribuição.
  • Verifique se os programas da faculdade e seus jogos têm suporte ou alternativas adequadas.
  • Mantenha o notebook conectado à energia durante a instalação.
  • Se o Windows usar criptografia, como BitLocker, guarde a chave de recuperação antes de alterar a inicialização.
  • Leia qual disco será alterado. A opção de apagar o disco pode remover o Windows e seus arquivos.

O que é dual boot?

Dual boot é manter dois sistemas instalados no mesmo computador e escolher qual iniciar ao ligá-lo. Eles não ficam rodando ao mesmo tempo. Isso permite continuar usando o Windows para tarefas que ainda dependem dele.

A configuração envolve dividir o espaço de armazenamento. Ela varia conforme o computador e a distribuição; não siga etapas de particionamento sem entender o que será alterado.

Alguns comandos para conhecer o terminal

Abra o terminal pelo menu de aplicativos. Digite um comando por vez e pressione Enter. Os exemplos abaixo não apagam arquivos e podem ser usados nas três distribuições.

pwd
Mostra o caminho da pasta em que o terminal está trabalhando.
ls
Lista os arquivos e pastas desse local. Itens ocultos não aparecem nessa listagem básica.
cd ~
Leva o terminal para sua pasta pessoal. O símbolo ~ representa essa pasta.
mkdir teste-linux
Cria uma pasta chamada teste-linux no local atual. Se ela já existir, o comando avisa.
cd teste-linux
Entra na pasta criada. O comando muda o local de trabalho do terminal, sem abrir uma janela.
cd ..
Volta para a pasta que contém a atual. Os dois pontos representam esse nível acima.

Para praticar, vá à pasta pessoal, crie a pasta de teste, entre nela e use pwd e ls. Você também pode encontrar essa pasta pelo gerenciador de arquivos.

Antes de copiar outros comandos da internet, procure entender o que fazem. Comandos de instalação e atualização variam entre distribuições.
