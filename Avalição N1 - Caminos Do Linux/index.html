Para quem este site foi feito

Você usa Windows e quer saber como é usar Linux? Este site reúne o básico para entender o sistema, escolher uma distribuição e fazer um primeiro teste. Não é preciso ter experiência com programação.

No uso cotidiano, Linux é o nome dado a uma família de sistemas que permite navegar, estudar, trabalhar e jogar. Mais precisamente, Linux é o núcleo que faz os programas e o computador trabalharem juntos. As distribuições completam essa base com aplicativos e uma interface.

Por que experimentar

O interesse pode começar pela vontade de conhecer outro sistema, escolher uma interface diferente ou entender melhor o computador. Muitas distribuições podem ser usadas sem pagar por uma licença, e seus programas costumam ser instalados por uma central de aplicativos.

A troca também exige atenção: aquele programa usado na faculdade ou um jogo específico pode não funcionar da mesma forma. Vale conferir o que você usa antes de decidir.

Você não precisa abandonar o Windows para começar. É possível testar algumas distribuições por um pendrive ou em uma máquina virtual, que funciona como um computador dentro de uma janela. Depois, se fizer sentido, os dois sistemas podem dividir o mesmo computador.

Liberdade para conhecer e modificar

“Software livre” é uma questão de liberdade, não de preço.

Fonte: Projeto GNU, O que é o software livre?

Essa ideia ajuda a entender por que existem tantos projetos diferentes construídos sobre Linux. Não é necessário modificar programas para usar o sistema, mas essa possibilidade faz parte de sua base.
